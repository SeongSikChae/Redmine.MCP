### W2. 검증 범위 — **A**

#### U1

```text
dotnet package list --vulnerable --include-transitive --project src/Redmine.MCP.Server
dotnet package list --deprecated --project src/Redmine.MCP.Server
dotnet build src/Redmine.MCP.Server
```

#### U2

```text

```

#### U3
