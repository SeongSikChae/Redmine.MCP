#### U1 — `RedmineClientTests`

- 상대 경로 바이트 GET 성공
- 동일 origin 절대 URL 성공
- 다른 origin 거부
- 4xx → `RedmineApiException`
- API 키 헤더 유지
- 요청 Accept에 `*/*`
- 기존 JSON GET 회귀(기존 테스트 유지)

#### U2 — `AttachmentDownloadTests`

- `.md` / text → `text`
- 바이너리 → `contentBase64`
- UTF-8 실패 → base64
- 5MiB 이하 인라인
- 초과 + 경로 없음 판정
- 초과 + 경로 있음 → 본문 생략 JSON 형태

#### U3 — `AttachmentToolsTests` + `Redmine22ContractTests`

- `attachmentId` 경로(메타 + 다운로드)
- `issueId` + `filename`
- 동명 파일 오류
- `contentUrl` origin 거부
- 작은 파일 인라인(+ 선택 저장)
- Description에 5MiB, `outputPath`는 서버 호스트

#### U4 — README 수동 확인

- 양쪽 README에 `download_attachment`
- 5MiB·`outputPath` 문구

## 구현

- 순서 U1 → U2 → U3 → U4. 단위별 구현 후 해당 검증을 통과한 뒤에만 다음 단위로 진행한다.
